# ICODE_MPPI 一键操作手册（可复制粘贴）

> 目录基准：`/home/wmh/ICODE/domo/ICODE_MPPI`

## 0. 进入目录与环境
```bash
cd /home/wmh/ICODE/domo/ICODE_MPPI
conda activate icode_mujoco
```

## 1. 分支切换
### 1.1 基线版（不含自适应）
```bash
cd /home/wmh/ICODE/domo/ICODE_MPPI
git checkout baseline_before_adaptive_20260313
```

### 1.2 自适应实验版
```bash
cd /home/wmh/ICODE/domo/ICODE_MPPI
git checkout exp_adaptive_try
```

## 2. 三个 5 障碍可视化场景
```bash
bash /home/wmh/ICODE/domo/ICODE_MPPI/scripts/viz_scene5_case1.sh
bash /home/wmh/ICODE/domo/ICODE_MPPI/scripts/viz_scene5_case2.sh
bash /home/wmh/ICODE/domo/ICODE_MPPI/scripts/viz_scene5_case3.sh
```

## 3. 在可视化中启用自适应调度器
在任意 viewer 命令末尾追加：
```bash
--adaptive-scheduler
```

推荐两组参数：

### 3.1 保守版
```bash
--adaptive-scheduler \
--adaptive-ema 0.12 \
--adaptive-mode-min-steps 20 \
--adaptive-tight-clearance 0.34 \
--adaptive-tight-clearance-exit 0.50 \
--adaptive-stuck-progress 0.045 \
--adaptive-osc-window 12 \
--adaptive-osc-threshold 3.2 \
--adaptive-dock-radius 0.70
```

### 3.2 激进版
```bash
--adaptive-scheduler \
--adaptive-ema 0.28 \
--adaptive-mode-min-steps 8 \
--adaptive-tight-clearance 0.42 \
--adaptive-tight-clearance-exit 0.56 \
--adaptive-stuck-progress 0.08 \
--adaptive-osc-window 8 \
--adaptive-osc-threshold 2.1 \
--adaptive-dock-radius 0.85
```

## 4. 延长“失败判定时间”（高难场景）
```bash
--max-steps 2200 \
--progress-window 45 \
--progress-min-delta 0.05 \
--adaptive-mode-min-steps 12 \
--adaptive-stuck-progress 0.05
```

## 5. 批量测试（无可视化）
```bash
python run_icode_mppi_e1_test.py \
  --device cuda \
  --planner-model icode \
  --checkpoint runs/icode_e1_passable35_uniform_4h/icode_best.pt \
  --output-dir runs/mppi_batch_eval \
  --random-obstacles \
  --max-steps 1200 \
  --adaptive-scheduler
```

## 6. 训练（GPU）
```bash
python train_icode_and_eval.py \
  --device cuda \
  --bundle datasets/e1_mix_train_bundle.npz \
  --save-dir runs/icode_train_new \
  --epochs 100000 --max-train-seconds 3600 \
  --batch-size 98304 --num-workers 6 \
  --hidden-dim 640 --num-layers 6 \
  --optimizer adamw --fused-optimizer \
  --scheduler cosine --lr 2e-4 --weight-decay 1e-5 \
  --amp bf16 --compile-mode default
```

## 7. 结果产物位置
- 训练权重：`runs/<name>/icode_best.pt`
- 训练日志：`runs/<name>/train.log`
- 测试指标：`runs/<name>/metrics.json`
- 轨迹图：`runs/<name>/trajectory_controls.png`
